# qy-pet

奶蛙桌宠 MVP：悬浮桌宠 + 交互式 root shell + 双窗格 root 文件管理。

## 功能
- 悬浮占位奶蛙（可拖拽、点击出气泡、大小可调、放出来/收起来）
- 交互式 su 行终端（持久会话、实时输出、历史命令、可直接运行菜单脚本选项）
- 双窗格文件管理（浏览/复制/剪切/粘贴/删除/改名/新建/chmod，点 .sh 弹菜单执行）

## 本地不打包，直接 GitHub Actions 云构建
1. 把本目录所有文件上传到仓库 main 分支；
2. Actions 自动运行 `构建调试APK`；
3. 在运行页底部 Artifacts 下载 `qy-debug-apk`，解压安装。

## 说明
- 桌宠当前是占位矢量图，后续替换奶蛙素材；
- 终端是交互式 su 行 shell，不是完整 PTY（无颜色/光标控制）；
- Root 依赖 KernelSU/Magisk/APatch 给本应用授权。
